Terms used here
Physical diskA real drive on a node, such as sda. Disk IOPS and MB/s are measured on the drive.
VolumeStorage a pod asks for, called a PersistentVolumeClaim. The pod reads and writes files in it.
Stored onWhere a volume's bytes live. A local-path volume is one folder on one node. A Longhorn volume keeps a copy (replica) on each node listed.
Pod disk useRead from the container runtime per device. Writes can sit in memory before they reach the disk, so a pod's number is an estimate.
